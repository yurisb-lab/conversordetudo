# Conversor de Tudo

Ferramentas para PDF, imagem, vídeo, áudio, planilhas e ZIP que rodam **direto no navegador**: nenhum arquivo é enviado para servidor, sem limite de tamanho ou quantidade, sem cadastro.

É um único arquivo: `index.html`.

## Publicar
- **GitHub Pages:** Settings → Pages → Branch `main` / pasta raiz → Save.
- **Netlify:** arraste a pasta (ou só o `index.html`) para app.netlify.com/drop.

Precisa de internet só para abrir o site e, na primeira vez, baixar o componente de cada tipo de ferramenta (ficam no cache do navegador).
